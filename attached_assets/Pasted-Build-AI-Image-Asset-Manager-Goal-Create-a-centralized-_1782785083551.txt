Build AI Image Asset Manager.

Goal:
Create a centralized image system for Publishing Center + Auto Content Engine.

Problem:
AI recommends image ideas, but there is no actual image library or image matching system.

Build a full AI Image Asset Manager.

==================================================
PHASE 1 — IMAGE LIBRARY
=======================

Create new page:
Admin → Image Asset Manager

Features:

* Upload image
* View all images
* Delete image
* Preview image
* Search/filter images

Grid view cards.

Each image should store:

* id
* fileUrl
* fileName
* topicTags[]
* cityTags[]
* category
* uploadDate

==================================================
PHASE 2 — IMAGE TAGGING
=======================

Each image can be tagged by:

Topics:

* Bed Bugs
* Roaches
* Ants
* Fleas
* Ticks
* Rats
* Mice
* Wasps
* Spiders
* Mosquitoes
* Moles

Categories:

* infestation
* prevention
* treatment
* warning
* educational
* branding
* seasonal

Cities:

* Foley
* Gulf Shores
* Orange Beach
* Fairhope
* Daphne
* Spanish Fort

Allow multi-tag selection.

==================================================
PHASE 3 — AI IMAGE MATCHING
===========================

Auto Content Engine should auto-recommend best image.

Example:
Post:
City = Foley
Topic = Roaches
Angle = Warning

AI searches image library and returns best match.

Ranking priority:

1. topic match
2. category match
3. city match

Show:

* Match Score (1–100)
* Selected Image

==================================================
PHASE 4 — PUBLISHING INTEGRATION
================================

Publishing Center:
When creating or editing a post:

Show:
Recommended Images panel

Auto Content Engine:
Queue Inspector expanded row should show:

* recommended image
* match score

==================================================
PHASE 5 — DIAGNOSTICS
=====================

System Diagnostics:
Add Image Engine section.

Show:

* total assets
* tagged assets
* untagged assets
* image coverage score

AI Suggestions:
Examples:

* “Roaches has 8 images — strong coverage.”
* “Mice has only 1 image — upload more.”
* “No seasonal images found.”

Goal:
AI Edge automatically pairs posts with best-fit images for better engagement.

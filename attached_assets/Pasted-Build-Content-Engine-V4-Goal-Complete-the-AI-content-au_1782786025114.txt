Build Content Engine V4.

Goal:
Complete the AI content automation loop.

Current flow:
AI generates post → scores post → recommends platform → recommends image

New flow:
AI generates post → scores post → selects best image → auto-attaches image → publishes → tracks performance → learns

==================================================
PHASE 1 — AUTO IMAGE ATTACHMENT
===============================

Auto Content Engine:
When generating posts:

1. Match best image from Image Asset Manager
2. Save matched image to social_posts

Store:

* matched_image_id
* matched_image_url
* image_match_score

If score >= 70:
Auto attach image to post.

If no good match:
Leave blank.

Queue Inspector:
Show:

* matched image thumbnail
* match score

==================================================
PHASE 2 — PUBLISHING INTEGRATION
================================

Publishing Center:
When viewing post:
Show attached image automatically.

Allow:

* Replace image
* Remove image
* Re-run image matching

Publish route:
Use attached image automatically.

==================================================
PHASE 3 — PERFORMANCE TRACKING
==============================

Track post performance.

Store:

* impressions
* reach
* clicks
* likes
* comments
* shares
* engagement_score

Per post analytics card:
Show performance score.

==================================================
PHASE 4 — AI LEARNING LOOP
==========================

AI should learn from successful posts.

Analyze:

* best topics
* best cities
* best post angles
* best platforms
* best posting times

Generate insights:
Examples:

* Warning posts perform best on Facebook
* Mosquito posts perform best in Gulf Shores
* 8 AM posts outperform 5 PM

==================================================
PHASE 5 — SMART RECOMMENDATIONS
===============================

Add recommendations panel:

Examples:

* Best next post angle: Warning
* Best topic this week: Mosquitoes
* Best city: Gulf Shores
* Best posting time: 8 AM

==================================================
PHASE 6 — DIAGNOSTICS
=====================

System Diagnostics:
Add Content Performance section.

Show:

* avg engagement score
* top performing topic
* top performing city
* top performing angle
* best posting time

Goal:
Content Engine becomes self-improving over time.

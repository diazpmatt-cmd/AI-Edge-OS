GLOBAL UI STATUS COLOR FIX — AI EDGE UNIVERSAL STATUS SYSTEM

Do not rebuild modules.

Problem:
The Publishing Center platform/status buttons are not following the new status color logic.
Facebook became light blue, Instagram/Google turn white, and Google should show red/blocked when unavailable.

Goal:
Apply one consistent status color system across the entire AI Edge platform.

GLOBAL STATUS COLORS:
GREEN = success / ready / published / connected / healthy
YELLOW = warning / scheduled / pending / needs attention
RED = failed / error / blocked / disconnected / unavailable
BLUE = active / processing / selected / in progress
GRAY = disabled / coming soon / not enabled

Important:
Platform identity colors should not override status colors.
A platform button/tag should communicate status first.

Apply across:
- Publishing Center
- Connected Accounts
- Command Center
- BizAI
- AI Receptionist
- Call Intelligence
- Lead Recovery AI
- AI Visibility Engine
- Local Presence Engine
- Revenue Attribution
- Client Onboarding
- Any badges, chips, pills, platform buttons, and status labels

PUBLISHING CENTER RULES:
Platform buttons:
- Selected + ready = BLUE
- Connected/ready status badge = GREEN
- Scheduled = YELLOW
- Failed/blocked/unavailable = RED
- Disabled/coming soon = GRAY

Specific behavior:
- Facebook connected and selected = BLUE button, GREEN ready/published status
- Instagram connected and selected = BLUE button, GREEN ready/published status
- Google Business selected while GBP API blocked/quota unavailable = RED or YELLOW warning, not white
- YouTube Shorts coming soon = GRAY
- TikTok coming soon/not approved = GRAY or RED depending if blocked

Status badges on posts:
- Published = GREEN
- Scheduled = YELLOW
- Failed = RED
- Processing/Publishing = BLUE
- Draft = GRAY

Create reusable helper if needed:
getStatusColor(status)
getPlatformStatus(platform)

PHASE 8 — AI RECEPTIONIST V2

Upgrade AI Receptionist from a hardcoded IVR into a configurable, scalable client-ready module.

OBJECTIVE:
Make AI Receptionist easy to deploy for every client with minimal setup.

CURRENT STATUS:
AI Receptionist V1 works:
- Press 1 → transfer
- Press 2 → callback
- Press 3 → voicemail

Now build V2.

BUILD:

1. Create AI Receptionist Settings Module
ROUTE:
/admin/ai-receptionist/settings

Add settings page with simple configuration cards.

SETTINGS:
- Business Name
- Greeting Script
- Transfer Phone Number
- Callback Message
- Voicemail Message
- Text Routing Message
- Business Hours
- After Hours Mode
- Voice Style
- Custom Greeting Audio URL

2. Add Press 4 — Continue by Text
Update IVR:

Press 1 → Speak to business
Press 2 → Callback request
Press 3 → Leave voicemail
Press 4 → Continue by text

FLOW:
If caller presses 4:
- send SMS to caller
- log outbound SMS
- log calls row:
    call_type = text_routing
    outcome = sms_sent

SMS:
Thanks for contacting {Business Name}.
Reply with:
- Name
- Location
- Service needed

We'll assist you shortly.

3. Custom Greeting Support
Support:
- TTS voice
OR
- custom uploaded greeting audio

If custom audio exists:
Use <Play>
Else:
Use <Say>

4. Business Hours Routing
Modes:
- Always AI First
- Business Hours Ring First
- After Hours AI Only

Logic:
During business hours:
- optionally ring business first

After hours:
- AI answers immediately

5. Voice Settings
Add selectable voice profiles:
- Female Warm
- Female Professional
- Male Professional
- Custom Audio

6. Database
Create ai_receptionist_settings table:
- id
- client_id
- business_name
- transfer_phone
- greeting_script
- callback_message
- voicemail_message
- text_routing_message
- custom_greeting_url
- voice_style
- business_hours_json
- after_hours_mode
- created_at
- updated_at

7. API
Create:
- GET /api/ai-receptionist/settings
- PUT /api/ai-receptionist/settings
- POST /api/ai-receptionist/test-sms
- POST /api/ai-receptionist/test-call-flow

VALIDATION:
- API builds clean
- Web builds clean
- Settings page loads
- Press 1 works
- Press 2 works
- Press 3 works
- Press 4 works
- Call Intelligence logs text routing

GOAL:
AI Receptionist should be deployable for new clients in minutes without editing code.

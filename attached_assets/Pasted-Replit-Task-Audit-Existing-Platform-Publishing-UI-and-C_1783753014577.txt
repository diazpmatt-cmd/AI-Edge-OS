Goal:

Determine what already exists and identify the smallest implementation required for:

1. Showing every supported social platform in Publishing Center and Content Autopilot, including platforms that are disconnected, pending approval, or coming soon.

2. Allowing the user to drag and reorder Command Center tiles and persist the preferred order.

This is an AUDIT-ONLY task.

Do not add database tables.

Keep this investigation targeted and credit-efficient.

PART A — Publishing Center

Inspect the actual Publishing Center page and report:

1. File path and route.

2. How platform buttons/cards are currently defined.

3. Whether the platform list is:
   - hardcoded
   - derived from connected accounts
   - filtered to connected providers only
   - generated from a shared provider configuration

4. Why the following platforms are not currently shown:
   - YouTube
   - TikTok
   - LinkedIn
   - Apple Business, if publishing support is planned
   - any other supported provider

5. Whether YouTube publishing or queue logic already exists anywhere in the codebase.

6. Whether TikTok publishing or queue logic already exists but is disabled pending approval.

7. Whether disconnected platforms can safely be displayed without enabling publishing actions.

8. Existing social-post data model fields used to represent platforms.

Confirm whether the canonical field is:

platforms: string[]

9. Existing queue and publish endpoints for every provider.

Create a provider matrix containing:

- provider
- UI currently visible
- connection status available
- content generation available
- queue endpoint available
- publishing endpoint available
- production-ready
- pending approval
- coming soon
- missing entirely

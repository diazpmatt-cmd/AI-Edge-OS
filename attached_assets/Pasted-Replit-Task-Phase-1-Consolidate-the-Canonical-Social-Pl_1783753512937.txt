Replit Task: Phase 1 — Consolidate the Canonical Social Platform Registry

Background:

The audit found that social platform definitions are duplicated across:

- src/lib/social-providers.ts
- ConnectionsPage.tsx
- SocialPublishingPage.tsx
- BBBContentAutopilotPage.tsx
- AutoContentEnginePage.tsx
- DashboardPage.tsx

The existing src/lib/social-providers.ts file should become the canonical source of truth.

Goal:

Consolidate provider metadata into one shared registry without changing current user-facing behavior.

This is Phase 1 only.

Do not add drag-and-drop yet.
Do not change publishing behavior.
Do not enable disconnected platforms yet.
Do not add LinkedIn publishing.
Do not modify backend provider integrations.
Do not redesign any pages.

Before changing code:

1. Reconfirm every current platform definition and caller.

2. Record the provider metadata currently duplicated in each file, including:
   - id
   - display label
   - description
   - abbreviation
   - icon
   - color
   - gradient/background
   - connection route
   - approval status
   - coming-soon status
   - publishing capability

3. Confirm the exact provider IDs currently used by APIs and database records.

Canonical registry:

Extend:

src/lib/social-providers.ts

Create a typed provider model that supports:

- id
- label
- shortLabel
- description
- abbreviation
- icon or iconKey
- color
- background or gradient
- connectionPath
- status
- capabilities

Use normalized statuses such as:

- operational
- connected
- disconnected
- pending_approval
- coming_soon
- unsupported

Add capability flags such as:

- connect
- generateText
- generateImage
- generateVideo
- queue
- publish
- schedule
- analytics

Important:

Capabilities describe what AI Edge currently supports in code.
Do not mark a capability true merely because the external platform supports it.

Expected provider coverage:

- facebook
- instagram
- google_business
- youtube
- tiktok
- linkedin

Apple Business may be included only if it already belongs in the product registry, but it must not be marked as a social publishing provider unless publishing support truly exists.

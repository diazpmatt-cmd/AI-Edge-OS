TARGET: Audit and Activate Content Autopilot V2

Before writing any new code, perform a complete audit of the existing project.

Part 1 — V2 Audit

Determine whether Content Autopilot V2 (or pieces of it) already exist anywhere in the project.

Search for existing functionality related to:

- Auto Content Engine
- Content Autopilot
- Publishing Center
- Media Engine
- Asset Library
- Apollos
- Morning Brief
- Mission Control
- Growth Execution
- BB&B Ops Center
- Publishing Status
- Review requests
- Scheduling
- Queue management
- Image recommendations
- Video recommendations
- Weekly content planning
- Local content generation
- Baldwin County / BB&B presets
- Service filtering
- Photo-driven content
- AI Suggestions

Report:

1. What V2 capabilities already exist.
2. Which ones are partially built.
3. Which ones are inactive, hidden, or disconnected.
4. Which ones are fully functional today.
5. Which ones are duplicated and should be consolidated.

Part 2 — Activate Existing V2

If V2 functionality already exists:

- Connect it.
- Enable it.
- Surface it in the UI.
- Reuse existing code instead of rebuilding it.
- Remove duplicate pathways where appropriate.

The objective is NOT to create another engine.

The objective is to make the existing engines work together as one workflow.

Preferred workflow:

Morning Brief
→ Mission Control
→ Content Autopilot
→ Media Engine / Asset Library
→ Publishing Center
→ Publishing Status
→ Growth Execution
→ End-of-Day Recap
→ Apollos

Part 3 — Build Only What Is Missing

Only after the audit:

- Build the missing pieces required to complete V2.
- Reuse existing components whenever possible.
- Do not duplicate code or create parallel systems.
- Keep the architecture clean and modular.

Part 4 — Deliver a V2 Status Report

Provide:

- Existing V2 features found
- Activated features
- New code written (if any)
- Duplicate systems consolidated
- Files changed
- Build status
- Overall V2 completion estimate (percentage)

Goal:

Content Autopilot V2 should feel like one integrated business workflow rather than a collection of separate pages.

Keep the focus on helping Bed Bugs & Beyond generate more inspections, reviews, and revenue—not on adding unrelated features.

TARGET: Build the Bed Bugs & Beyond Revenue-First Content Autopilot scheduler.

PRIMARY GOAL

Convert the current template-driven Content Autopilot into a scheduled, continuously operating content engine for Bed Bugs & Beyond.

The engine must generate fresh content across all currently active pest-control services while explicitly excluding termites from active promotion.

IMPORTANT BUSINESS RULE

Bed Bugs & Beyond does NOT currently offer termite service.

Termites must be modeled as:

status: coming_soon

The system must not:

- generate termite service offers
- claim BB&B treats termites
- recommend termite booking
- publish termite-related calls to action
- let the AI receptionist imply termite service is available

Termite content may only say the service is coming soon if Matthew explicitly enables that type of announcement later.

ENGINEERING RULES

Follow:

1. Audit
2. Consolidate
3. Verify
4. Expand

Do not:

- create a second scheduler
- create a second service registry
- duplicate provider logic
- hard-code pest names throughout page JSX
- publish automatically before the scheduling and approval model is defined
- modify unrelated mobile code

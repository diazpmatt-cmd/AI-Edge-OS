--------------------------------------------------
PHASE 3 — DEFINE STATUS RULES
--------------------------------------------------

Use ONLY these four operational states.

READY

Meaning:

Platform is connected.

Publishing works.

No action needed.

Color:

Green

Examples:

Facebook

Instagram

Google Business (when quota restored)

YouTube

--------------------------------------------------

ACTION REQUIRED

Meaning:

Platform exists.

Publishing is possible after a user action.

Examples:

Reconnect account

Google quota pending

OAuth renewal

Waiting on approval email

Needs media

Needs title

Needs payment

Needs verification

Color:

Yellow

--------------------------------------------------

BLOCKED

Meaning:

Publishing cannot occur.

No backend exists.

Feature disabled.

Platform unsupported.

API unavailable.

Fatal configuration issue.

Color:

Red

Examples:

Missing publish handler

API removed

Unsupported workflow

--------------------------------------------------

PENDING

Meaning:

Future feature.

Coming soon.

Not yet released.

Visible for roadmap only.

Color:

White badge

Neutral card

Gray border

PART 2 — IMPLEMENT THE FIX

Refactor the actual visible Command Center so its tiles can be reordered.

Requirements:

1. Use the existing Framer Motion dependency.
2. Use one canonical ordered tile configuration.
3. Prefer Framer Motion Reorder.Group and Reorder.Item unless the audit proves another existing implementation should be reused.
4. Dragging must visibly move the tile while the pointer is held.
5. Dropping must update the tile order immediately.
6. Save the resulting order to localStorage.
7. Restore the saved order after refresh.
8. Safely normalize saved data:
   - ignore unknown tile IDs,
   - remove duplicates,
   - append newly introduced tiles in canonical default order,
   - fall back safely if stored JSON is corrupt.
9. Use stable tile IDs, not labels or array indexes.
10. Preserve all current tile click actions and navigation.
11. Do not make normal button clicks accidentally start dragging.
12. Add a visible drag handle if dragging the full tile conflicts with clicking.
13. Support desktop pointer dragging and reasonable touch behavior.
14. Verify no parent element uses CSS that blocks dragging, such as incorrect pointer-events, overflow, touch-action, or z-index behavior.
15. Do not add Clerk persistence yet. Keep persistence behind a small helper or hook so Clerk metadata can replace localStorage later.

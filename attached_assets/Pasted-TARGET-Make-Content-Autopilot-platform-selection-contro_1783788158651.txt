TARGET: Make Content Autopilot platform selection control the complete content and media workflow for the Bed Bugs & Beyond pilot.

PRIMARY GOAL

The platform buttons in Content Autopilot must become the single control point for deciding which platform-specific content packages are created.

Current active BB&B pilot platforms:

- Facebook
- Instagram
- Google Business Profile
- YouTube

When Matthew selects any combination of those platforms and presses Generate, AI Edge must create content only for the selected platforms.

Do not build separate disconnected generators for each page.

IMPORTANT ENGINEERING RULES

Follow:

1. Audit
2. Consolidate
3. Verify
4. Expand

Do not:

- create another provider registry
- create another platform selection system
- hard-code a second pilot platform list
- rebuild Content Autopilot
- add TikTok, LinkedIn, Pinterest, or Nextdoor to this phase
- claim finished video generation exists unless a real video file is created
- weaken authentication
- modify unrelated mobile code

Trace the selected platform IDs from:

1. Content Autopilot platform cards
2. localStorage restoration
3. Generate Weekly Content action
4. template/content creation
5. draft creation
6. media requirement creation

8. Publishing Center

Confirm:

- whether image ideas are shared or platform-specific
- whether YouTube receives title and description fields or only a caption
- whether media assets are currently generated, uploaded, or only suggested
- whether queueing and generation use the same selected platform set

Report the exact gaps before implementation.

PHASE 2 — DEFINE ONE PLATFORM CONTENT PACKAGE MODEL

Create or reuse a shared content-package model keyed by canonical platform ID.

Each generated platform package should support:

- platformId
- campaignId
- title where applicable
- caption or description
- CTA
- hashtags or tags
- content status
- required media type
- required placement
- width
- height
- aspect ratio
- media asset ID when available
- thumbnail asset ID when applicable
- publish capability
- manual action required
- queue status

Do not force every platform into identical caption-only fields.

Preserve backward compatibility with existing social post records.

If API or schema changes are needed:

- update OpenAPI first
- update Zod schemas
- regenerate clients
- update all consumers

PHASE 3 — SELECTED PLATFORM GENERATION

When Generate is pressed:

1. Read the current selected pilot platform IDs.
2. Reject generation if none are selected.
3. Create one platform-specific package for every selected platform.
4. Create no package for an unselected platform.
5. Use the canonical provider registry and content profiles.
6. Persist packages under one campaign or generation run.
7. Show a clear generated summary by platform.
8. Preserve the user’s selected platform set.

Example:

If Facebook and YouTube are selected:

- create Facebook package
- create YouTube package
- do not create Instagram package
- do not create Google package

PHASE 4 — FACEBOOK PACKAGE

For Facebook, create:

- Facebook-specific caption
- CTA
- hashtag strategy
- image requirement
- recommended placement:
  - 1:1 square
  - or 4:5 portrait where appropriate
- image dimensions
- draft/queue state
- direct-publish readiness state

Do not reuse the exact Instagram caption unless the content profile intentionally allows it.

PHASE 5 — INSTAGRAM PACKAGE

For Instagram, create:

- Instagram-specific caption
- hashtags
- CTA
- image requirement
- feed placement:
  - 4:5 preferred
  - 1:1 fallback
- optional 9:16 Story/Reel concept
- image dimensions
- draft/queue state
- direct-publish readiness state

Do not claim Reel creation unless a real vertical video asset exists.

PHASE 6 — GOOGLE BUSINESS PROFILE PACKAGE

For Google Business Profile, create:

- concise local-business post
- Baldwin County local relevance
- CTA
- image requirement or optional-image state
- recommended placement:
  - 1:1
  - or 4:3 if supported by the existing media system
- manual-publish status while Google API quota remains zero
- copy-ready content
- clear “Manual publish required” label

Google must remain usable manually even while automated publishing is blocked.

PHASE 7 — YOUTUBE PACKAGE

For YouTube, create a richer package:

- title
- description
- tags
- CTA
- thumbnail requirement
- thumbnail dimensions:
  - 1280 x 720
  - 16:9
- video requirement
- video type:
  - Short
  - or standard video
- recommended video dimensions:
  - 1080 x 1920 for Shorts
  - 1920 x 1080 for standard video
- script or outline
- publish-readiness state
- “Video file required” status until an MP4 exists

Do not pretend the written package is a finished video.

PHASE 8 — MEDIA REQUIREMENTS AND VARIANTS

Add or reuse canonical media placement profiles for the four pilot platforms.

At minimum support:

- Facebook square: 1080 x 1080
- Facebook portrait: 1080 x 1350
- Instagram portrait: 1080 x 1350
- Instagram square: 1080 x 1080
- Instagram vertical: 1080 x 1920
- Google square: 1080 x 1080
- YouTube thumbnail: 1280 x 720
- YouTube Short: 1080 x 1920
- YouTube standard video: 1920 x 1080

Each placement profile should define:

- placement ID
- platform ID
- width
- height
- aspect ratio
- label
- safe-zone guidance
- whether image, thumbnail, or video is required

Do not scatter these values across page JSX.

PHASE 10 — RESULTS UI

Each selected platform should display:

- content preview
- platform-specific fields

- manual action required
- edit capability
- approval state

Unselected platforms should not appear in the generated results.

The platform selection cards remain the source of truth.

PHASE 11 — QUEUE BEHAVIOR

Queue All must operate only on selected generated packages.

Requirements:

- Facebook queues only when selected
- Instagram queues only when selected
- Google creates a manual-ready draft while API quota is blocked
- YouTube queues only when required metadata exists
- YouTube cannot be marked publish-ready without a real video asset
- no unselected platform can be queued
- no duplicate package is created on repeated clicks without explicit regeneration

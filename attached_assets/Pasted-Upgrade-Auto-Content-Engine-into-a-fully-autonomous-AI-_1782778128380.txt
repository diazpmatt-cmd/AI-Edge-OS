Upgrade Auto Content Engine into a fully autonomous AI marketing engine.

Goal:
AI Edge should automatically generate, schedule, and queue content for each client with minimal human input.

==================================================
PHASE 1 — CLIENT CONTENT SETTINGS
=================================

For each client/business, store:

{
businessName,
industry,
serviceAreas: [],
servicesTopics: [],
postingFrequency,
preferredPlatforms: [],
preferredTimes: [],
toneStyle,
ctaPreference,
autoGenerateEnabled
}

Example: Bed Bugs & Beyond

industry: pest_control

serviceAreas:

* Daphne
* Foley
* Gulf Shores
* Orange Beach
* Fairhope

servicesTopics:

* Bed Bugs
* Ants
* Roaches
* Fleas
* Ticks
* Rats
* Mice
* Mosquitoes
* Spiders
* Termites

postingFrequency:

* daily OR every_other_day

preferredPlatforms:

* facebook
* google

preferredTimes:

* 08:00
* 12:00
* 17:00

toneStyle:

* professional
* educational
* urgent
* friendly

ctaPreference:

* call_now
* learn_more
* book

autoGenerateEnabled:
true

==================================================
PHASE 2 — AI CONTENT GENERATION
===============================

AI should automatically generate posts by rotating:

1. Service area
2. Topic
3. Post angle
4. Posting time

Post angles:

* educational
* warning
* promotional
* seasonal
* faq
* testimonial
* prevention
* emergency

Example combinations:

Topic = Ants
Area = Daphne
Angle = Warning

Topic = Bed Bugs
Area = Gulf Shores
Angle = Educational

Topic = Mosquitoes
Area = Foley
Angle = Seasonal

AI generates:

* caption
* CTA
* optional image prompt
* suggested platforms

Example output:
{
city: "Daphne",
topic: "Ants",
angle: "warning",
caption: "Ants invading your Daphne home? Don’t wait until a small problem becomes a major infestation. Call Bed Bugs & Beyond today for fast, reliable pest control.",
cta: "call_now",
platforms: ["facebook", "google"]
}

==================================================
PHASE 3 — AUTO SCHEDULING ENGINE
================================

Automatically build next 7–14 days of content.

Rules:

* avoid repeating same city twice in a row
* avoid repeating same pest twice in a row
* rotate posting times
* rotate post angles
* balance service areas evenly

Example schedule:
Mon 8AM → Ants / Daphne
Tue 12PM → Roaches / Foley
Thu 5PM → Bed Bugs / Gulf Shores
Sat 8AM → Mosquitoes / Orange Beach
